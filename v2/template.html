操作說明

Keyboard & mouse

換頁

  • → ← / PgDn PgUp：下一頁 / 上一頁
  • Home End：第一頁 / 最後一頁；網址加 #25 直接開到第 25 頁
  • Shift+→：跳到下一章

動畫與互動

  • Space：本頁動畫下一步；跑完才換頁（Shift+Space 退一步）
  • A：自動播放本頁動畫；R：重播
  • 虛線底的粗體字是專有名詞，滑過會出現解釋；G 打開完整名詞表

其他

  • N 講者筆記（含本頁來源連結）、O 目錄、F 全螢幕、Esc 關閉
  • 「列印 / PDF」會先把所有動畫停在最終狀態，再交給瀏覽器輸出。請選「儲存為 PDF」、 勾選「背景圖形」、關閉「頁首及頁尾」、紙張用 CSS 尺寸。
